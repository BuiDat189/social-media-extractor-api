Universal Social Media Video & Audio Extractor

Full-Stack Web Application & High-Performance Python API

Quick Start (Local Setup)

# 1. Install dependencies

pip install -r requirements.txt

# 2. Run the server

python -m uvicorn app.main:app --reload --port 8000

Once started, open http://127.0.0.1:8000 to access the ready-to-use web downloader UI, or /docs for the interactive Swagger API documentation.

Docker 1-Click Deployment

A production-ready Dockerfile is included. Build and deploy anywhere with:

docker build -t media-extractor .

docker run -d -p 8000:8000 media-extractor

Free Cloud Hosting (Render / Railway / Vercel)

  1. Push the source code to your GitHub repository.
  2. Connect your repository to Render.com.
  3. The included render.yaml automatically configures your service.
  4. Your live HTTPS API will be deployed in under 2 minutes.
